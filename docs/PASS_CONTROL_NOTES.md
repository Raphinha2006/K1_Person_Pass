## 精度优化的建议顺序

1. 固定一个球、一个接球人和相同初始位置，重复测试并记录真实落点。
2. 先校准前进、侧移和转向的有效速度，再改善 `Adjust` 的收敛和对准计时。
3. 控制稳定后，再标定行走推踢的速度、持续时间与球滚动距离。
4. 最后验证左前方、正前方和右前方，以及目标消失、中断和重新触发。

当前参数基线：`stand_off=0.45 m`、`alignment=0.1 rad`、连续对准 `0.35 s`、
`kick_speed=0.35 m/s`、`kick_duration=2.0 s`。
以上是待验证方向，不代表已经确定需要修改这些数值。
